# Video Interview Architecture - المعمارية

## STEP 1 - شرح المعمارية

### لماذا الواجهة الأمامية لا تتصل مباشرة بـ Beyond Presence؟

**الأسباب:**

1. **الأمان:**
   - الواجهة الأمامية مكشوفة للمستخدم
   - ربطها مباشرة بـ Beyond Presence يعرض API keys والبيانات الحساسة
   - Backend يحمي هذه المعلومات

2. **التحكم المركزي:**
   - Backend ينسق بين LLM و ElevenLabs و Beyond Presence
   - بدون Backend، الواجهة الأمامية تحتاج اتصالات متعددة معقدة

3. **المعالجة:**
   - Backend يعالج الصوت (تحويل إلى نص، تحليل) قبل الإرسال
   - الواجهة الأمامية لا تستطيع القيام بهذه المعالجة

4. **التخزين:**
   - Backend يحفظ سجل المقابلة والتقييمات
   - الواجهة الأمامية لا تستطيع الوصول لقاعدة البيانات مباشرة

---

### لماذا الصوت يجب أن يمر عبر Backend؟

**الأسباب:**

1. **التحليل:**
   - Backend يحول الصوت إلى نص (STT - Speech-to-Text)
   - يرسل النص إلى LLM للفهم والرد

2. **التنسيق:**
   - Backend يوزع الصوت على:
     - **LLM** (للنص والفهم)
     - **ElevenLabs** (لصوت الرد)
     - **Beyond Presence** (لحركة الأفاتار)

3. **التخزين:**
   - حفظ المحادثة والتقييمات
   - الواجهة الأمامية لا تستطيع الوصول لقاعدة البيانات

4. **الأمان:**
   - التحقق من الهوية والصلاحيات
   - حماية البيانات الحساسة

---

### لماذا الـ Backend هو المتحكم الرئيسي؟

**الأسباب:**

1. **التنسيق:**
   - يربط LLM و ElevenLabs و Beyond Presence
   - ينسق بين الخدمات المختلفة

2. **المنطق:**
   - يحدد متى يرسل إلى كل خدمة
   - يتحكم في تدفق البيانات

3. **الأمان:**
   - يتحكم في الوصول والبيانات
   - يحمي API keys والبيانات الحساسة

4. **المراقبة:**
   - يتتبع الحالة والأخطاء
   - يسجل الأحداث

5. **التخزين:**
   - يحفظ كل البيانات
   - الواجهة الأمامية لا تستطيع الوصول لقاعدة البيانات

---

## ملخص:

- **الواجهة الأمامية:** تعرض فقط (Display Only)
- **Backend:** يتحكم بكل شيء (Controller)
- **LLM:** معالجة النص فقط
- **ElevenLabs:** توليد الصوت
- **Beyond Presence:** توليد فيديو الأفاتار

**السبب الرئيسي:** الأمان + التحكم المركزي + المعالجة

---

## تدفق البيانات:

1. **من المستخدم:**
   - الميكروفون → الواجهة الأمامية (التقاط فقط)
   - الواجهة الأمامية → Backend (إرسال الصوت)

2. **في Backend:**
   - استقبال الصوت
   - تحويل الصوت إلى نص (STT)
   - إرسال النص إلى LLM
   - إرسال الصوت إلى ElevenLabs و Beyond Presence

3. **من Backend:**
   - استقبال النص من LLM
   - إرسال الصوت إلى ElevenLabs و Beyond Presence (منفصلين)
   - الواجهة الأمامية تعرض الأفاتار مباشرة من Beyond Presence

4. **إلى المستخدم:**
   - الواجهة الأمامية تعرض الفيديو والصوت
   - المستخدم يرى الأفاتار ويسمع الصوت
