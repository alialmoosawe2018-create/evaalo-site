# بناء التطبيق - React Native وبدائل الموبايل

> تم حفظ هذه الوثيقة للرجوع إليها لاحقاً عند تنفيذ التحويل.

---

## 1. الفرق بين React و React Native

### إعادة الاستخدام مقابل إعادة الكتابة

| الجزء | إعادة الاستخدام | التفاصيل |
|-------|-----------------|----------|
| **منطق التطبيق** | غالباً | الـ state، الـ API calls، المنطق العام |
| **التصميم/الواجهة** | إعادة كتابة | المكونات، التنسيق، طريقة الـ styling |

### أمثلة المكونات

**React (ويب):**
```jsx
<div>
  <input type="text" />
  <button>Submit</button>
</div>
```

**React Native:**
```jsx
<View>
  <TextInput />
  <TouchableOpacity><Text>Submit</Text></TouchableOpacity>
</View>
```

## 2. تقدير الوقت التقريبي

| نوع الصفحة | الوقت التقريبي | أمثلة |
|------------|-----------------|-------|
| بسيطة | 1–2 ساعة | Form، صفحة بسيطة |
| متوسطة | 2–4 ساعات | Dashboard، Candidates |
| معقدة | 4–8 ساعات+ | VideoInterviewCall، LiveKit، WebSocket |

**إجمالي تقديري لتطبيق كامل:** حوالي 30–50 ساعة عمل أو أكثر حسب عدد الصفحات وتعقيدها.

---

## 3. خيارات أسرع

| الخيار | الوقت | الوصف |
|--------|-------|-------|
| **Capacitor** | 2–4 ساعات | تغليف الفرونت الحالي (React/ويب) كتطبيق موبايل دون إعادة كتابة الواجهة |
| **PWA** | ساعة أو أقل | جعل الموقع قابلاً للتثبيت كتطبيق من المتصفح |

---

## 4. ما يمكن تنفيذه في التحويل

| المهمة | التفاصيل |
|--------|----------|
| إنشاء مشروع React Native | هيكلة المشروع والملفات |
| تحويل الصفحات | Form, Dashboard, Candidates, WrittenInterview... |
| تحويل المكونات | NewInterviewSidebar، وغيرها |
| ربط الـ API | الاتصال بنفس الباكند الحالي |
| توجيهات واضحة | خطوات للإعداد والتشغيل |

---

## 5. ما ستحتاج فعله (المستخدم أو مطوّر)

| المهمة | السبب |
|--------|-------|
| تثبيت Node.js | ضروري لتشغيل المشروع |
| تثبيت Expo Go على الموبايل | لتجربة التطبيق بسرعة |
| أو تثبيت Android Studio | لبناء نسخة أندرويد |
| حساب مطوّر Apple (مدفوع) | فقط إذا أردت نشر التطبيق على App Store |

---

## 6. الخطة المقترحة (Expo)

سنستخدم **Expo** لأنه:

1. أسهل للمبتدئين
2. يمكن تجربته مباشرة على الموبايل عبر تطبيق Expo Go
3. لا يتطلب إعداداً معقداً في البداية

---

## 7. ترتيب التنفيذ

1. إنشاء مشروع React Native (Expo)
2. تحويل صفحة الاستمارة Form.jsx
3. تحويل لوحة التحكم Dashboard
4. تحويل بقية الصفحات

---

## 8. ملاحظات مهمة

- بعض الميزات المتقدمة (مثل LiveKit للمكالمات المرئية) قد تحتاج إضافات خاصة في React Native.
- الخلاصة: **React Native = إعادة كتابة الواجهة بمكونات React Native، لكن إعادة استخدام كثير من المنطق.**
- إن كان الهدف الوصول السريع للموبايل، **Capacitor** أو **PWA** أسرع من React Native.

---

## 9. الخطوة التالية

عند الجاهزية، اكتب **"ابدأ"** لبدء إنشاء مشروع React Native وتهيئته، ثم إضافة الصفحات تدريجياً.
