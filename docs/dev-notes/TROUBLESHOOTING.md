# معالجة أخطاء الكونسول

## 1. ERR_CONNECTION_REFUSED (المنفذ 5000)

**السبب:** الخادم الخلفي (Backend) غير شغّال.

**الحل:** تشغيل الباك إند قبل تشغيل الفرونت إند:

```bash
# من المجلد الرئيسي للمشروع
cd cursor-react

# تشغيل الباك إند
npm run dev:backend
```

أو تشغيل كلاهما معاً:

```bash
npm run dev:all
```

تأكد أن الباك إند يعمل على المنفذ 5000 قبل فتح صفحة المقابلة.

---

## 2. [SpeechRecognition] network + الترانسكربت يظهر لكن الإيجنت لا يرد

**السبب:** كان الفرونت يستخدم Web Speech API (المتصفح) بالتوازي مع الباك إند. الخطأ يظهر لأن Web Speech API يتصل بخدمة Google.

**الحل المطبق:** تم تعطيل Web Speech API. الترانسكربت يأتي الآن **فقط** من الباك إند عبر WebSocket (Speechmatics/Deepgram). لن يظهر خطأ network.

**إذا ظهر الترانسكربت لكن الإيجنت لا يرد:**
- تحقق من لوقز الباك إند:
  - `[STT FINAL]` = وصول transcript من STT
  - `[TRANSCRIPT]` = إرسال للـ LLM
  - `[SKIP]` = تم تجاهل النص (كلمات قليلة، ضوضاء، أو تكرار)
- تأكد أن الجملة 3+ كلمات و 10+ أحرف
- خُفّض حد الصوت (RMS) من 100 إلى 50 لالتقاط الصوت الهادئ

## 3. favicon.ico 404

**السبب:** لا يوجد ملف favicon في المشروع.

**الحل:** أضف ملف `favicon.ico` داخل مجلد `apps/frontend/public/`:

```html
<!-- في index.html -->
<link rel="icon" href="/favicon.ico" type="image/x-icon">
```

---

## 4. ScriptProcessorNode deprecated

**السبب:** المتصفح يستخدم واجهة قديمة لمعالجة الصوت.

**الحل:** هذا تحذير من المتصفح، لا يؤثر على عمل التطبيق حالياً. يمكن تجاهله أو إصلاحه لاحقاً عبر الانتقال إلى `AudioWorkletNode`.
