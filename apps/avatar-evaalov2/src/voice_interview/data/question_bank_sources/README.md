# Question bank sources

Canonical Evaalo interview question banks for the voice agent (**3+2 model**).

## Model

- **10 anchor questions** per category / job override — the agent picks ~3 as inspiration, not a rigid script.
- **2+ dynamic follow-ups** per anchor — generated by the LLM from the candidate's answer.
- Resolution is logged as `question_bank_resolved` and included in session shutdown telemetry.

## Fallback chain

1. `job_id` / `question_bank_job_id` → `jobs` section (Mongo posting)
2. `position_slug` → `jobs` override (`override_used=true`); alias slugs resolve to their canonical bank
3. `position_registry` → `categories` (granular per-role banks)
4. `industry_family` → `industry_families` (safety net, 8 anchors each)
5. `__default__` if `INTERVIEW_QUESTIONS_USE_DEFAULT_FALLBACK=true`
6. `start_no_bank`

## Structure

- **139** canonical positions, **6** alias slugs (e.g. `software-developer → software-engineer`,
  `procurement-office → procurement-officer`).
- **98** granular categories (10 questions each) and **10** industry families (8 questions each).
- `jobs[slug]` is generated automatically as `CATEGORIES[registry[slug].category]`.
  `alias_of` slugs are **skipped** in `jobs` (canonical resolution + `title_index` cover them),
  so the bank stays de-duplicated.

## Files

| File | Purpose |
|------|---------|
| `position_catalog.py` | Auto-generated: titles + category + industry_family, slug & title aliases |
| `build_question_bank.py` | Auto-generated: `CATEGORIES` / `INDUSTRY_FAMILIES` content + generator |
| `../interview_questions.json` | Runtime bank loaded by `job_questions.py` |

`position_catalog.py` and the `CATEGORIES` / `INDUSTRY_FAMILIES` content blocks were code-generated
from the curated bank. To change question content or taxonomy, edit those source files directly
(they are the single source of truth) and regenerate the JSON.

## Regenerate JSON

From `apps/avatar-evaalov2`:

```powershell
uv run python src/voice_interview/data/question_bank_sources/build_question_bank.py
```

The generator warns on unknown categories/families and missing alias targets, and reproduces
`title_index` from `POSITION_ROWS` + `TITLE_ALIASES`.

## Slug parity

Slugs must match backend `slugForJobQuestions()` in `apps/backend/src/routes/videoInterview.ts`
and agent `slug_from_position_label()`. `slug_from_position_label(title)` must reproduce every
registry key (enforced by tests).
